# Ассортимент категории «Чемоданы и аксессуары для путешествий»

- `aktivnyy_assortiment_<дата>.csv` — выгрузки активного ассортимента категории из товарной системы (одна строка — один активный SKU).
- `zhurnal_izmeneniy_assortimenta_<дата>.csv` — выгрузка журнала изменений ассортимента категории: каждый ввод и вывод SKU с датой, когда изменение вступило в силу в товарной системе. Журнал ведётся с 01.06.2026.
- Дата в имени файла — дата выгрузки. Файлы сохраняются в папку вручную, по мере необходимости, не по расписанию.
- Чехлы для чемоданов (матрица запуска) в выгрузки пока не входят: субкатегория ещё не заведена в товарной системе.

## Подкатегории

| Подкатегория | Что входит |
| --- | --- |
| Чемоданы пластиковые | чемоданы с жёстким корпусом (ABS, поликарбонат, полипропилен) |
| Чемоданы тканевые | чемоданы с мягким корпусом |
| Дорожные сумки | сумки и портпледы |
| Рюкзаки дорожные | рюкзаки для ручной клади |
| Багажные весы | ручные безмены для взвешивания багажа |
| Аксессуары для путешествий | замки TSA, бирки, ремни для багажа |
