# Памятка для категорийных менеджеров: разделы сайта

Отдел электронной коммерции сети «Орбита», редакция от 01.09.2026.

- «Новинки» — товары, введённые в ассортимент за последние 30 дней. Раздел обновляется каждую ночь.
- «Хиты сезона» — 50 товаров категории с наибольшими продажами за прошлую неделю; список обновляется по понедельникам.
- «Финальная распродажа» — раздел собирается автоматически: в него попадают только товары, вывод которых из ассортимента уже вступил в силу в товарной системе, пока на складах остаются запасы. Вручную товары в раздел не добавляются.
- Баннеры на главной странице заказываются заявкой в отдел не позднее чем за 5 рабочих дней до старта.
