# Гайд по оформлению презентаций (защиты стажировок и проектов)

Отдел обучения сети «Орбита», редакция 2026 г.

## Оформление

1. Фон слайда — белый; акцентный цвет — оранжевый фирменный. Не больше трёх акцентных цветов на слайде.
2. Заголовок — не длиннее одной строки; минимальный кегль основного текста — 24 пт: презентацию смотрят из зала.
3. Один слайд — одна мысль. Текст над схемами не ставим.

## Цифры на слайдах

4. Все цифры на слайдах должны совпадать с исходными файлами (выгрузками, матрицами); источник указывается в заметках докладчика.
5. Проценты на слайдах указываются целым числом, знак % — через пробел. Пример оформления: «Доля новинок в ассортименте — 12 %» (43 SKU из 331, выгрузка на 01.03.2026).
6. Денежные суммы — в рублях с пробелом между разрядами, без копеек.
7. Даты — в формате ДД.ММ.ГГГГ.
