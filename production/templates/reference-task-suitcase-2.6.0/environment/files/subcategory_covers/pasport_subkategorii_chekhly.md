# Паспорт субкатегории «Чехлы для чемоданов»

Категория: «Чемоданы и аксессуары для путешествий», сеть «Орбита». Составитель: П. Крылова (стажёр), согласовано: А. В. Лебедева (категорийный менеджер). Редакция от 21.09.2026.

## 1. Общее описание продукта

Чехол для чемодана — эластичная защитная накидка на корпус чемодана. Защищает от царапин, грязи и повреждений при транспортировке багажа, помогает быстро узнать свой чемодан на багажной ленте. Покупатель выбирает чехол по размеру своего чемодана, по типу корпуса и по внешнему виду.

Компонентный состав: полотно (спандекс с полиэстером, плотность 180–260 г/м²), молния по боковому шву, прорези под ручки и колёса, застёжка-липучка внизу.

## 2. Термины

- SKU — одна товарная позиция матрицы (одна строка файла матрицы, один артикул).
- Дизайн — рисунок (принт) на полотне, с которым чехол поступит в продажу.
- Цвет фона — основной цвет полотна, по нему определяется кластер цвета (раздел 5).
- Закупочная цена — цена, по которой сеть покупает чехол у поставщика, без НДС.

## 3. Материал корпуса

Чехол подбирается под корпус чемодана, на который его надевают:

- жёсткий корпус — пластиковые чемоданы (ABS, поликарбонат, полипропилен): полотно плотнее, прорези под ручки усилены;
- мягкий корпус — тканевые чемоданы (полиэстер, нейлон): полотно мягче, с запасом под внешние карманы.

## 4. Размерная сетка

Размер чехла в сегментации определяется по высоте чемодана, на который рассчитан чехол, по сетке категории:

- S (ручная кладь): высота чемодана до 55 см включительно
- M (средний): высота чемодана 56–65 см
- L (большой): высота чемодана 66–75 см
- XL (семейный): высота чемодана 76 см и выше

## 5. Кластер цвета

Используем кластеры, а не отдельные оттенки, чтобы не дробить ассортимент. Кластер цвета присваивается по цвету фона чехла (основному цвету полотна) по таблице 5.1.

## 6. Сегментация

Сегментация субкатегории строится на основе следующих характеристик: материал корпуса + кластер цвета + размер. Сегменты — это группы товара, а не группы покупателей. Например, чехол для жёсткого чемодана высотой 52–57 см на графитовом полотне входит в сегмент «жёсткий корпус + Тёмные базовые + M», а чехол для тканевого чемодана высотой 71–77 см на мятном полотне — в сегмент «мягкий корпус + Яркие + XL».

## 7. Тренды рынка и проблемные места

- Растёт доля поликарбонатных чемоданов — растёт спрос на плотные чехлы под жёсткий корпус.
- Чехлы с принтами покупают как способ выделить свой чемодан; однотонные — как защиту.
- Проблемные места чемоданов: царапины на глянцевом пластике, сломанные колёса и ручки, разошедшиеся молнии у тканевых моделей.

## 8. Ценовой сегмент

Ценовой сегмент чехла определяется по его закупочной цене. Границы сегментов, руб.:

- базовый: до 599
- средний: 600–749
- верхний: от 750
