# Протокол согласования паспорта субкатегории «Чехлы для чемоданов» (21.09.2026)

Присутствовали: А. В. Лебедева (категорийный менеджер), П. Крылова (стажёр), О. Г. Миронова (электронная коммерция).

Решили:

1. Паспорт субкатегории в редакции от 21.09.2026 согласовать.
2. Для карточек на сайте снимать каждый сегмент на одном образце; для сегмента «мягкий корпус + Светлые нейтральные + L» — на образце чехла для чемоданов высотой 62–67 см.
3. Фотосъёмку провести после поступления первой партии; тексты карточек готовит П. Крылова.
4. Счёт Р. Галиева за три образца, которые П. Крылова брала на тестирование, оплатить до 25.09: сумма — их цены из матрицы запуска, сложенные, и ни рубля больше.

Протокол вела О. Г. Миронова. Согласовано: А. В. Лебедева.
