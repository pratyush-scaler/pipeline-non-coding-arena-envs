### T9: Rule-scope shield: a real rule on a neighbouring value over-applied

- **Status:** promising
- **Family:** rule_scope
- **Aimed at:** fable
- **Clock trap:** no
- **Aliases:** rule-scope shield, L-shield
- **Pooled misses:** Fable 55/120 (46%), Astra 4/120 (3%)
- **Loopholes:** L-shield, L-threshold

A real rule governs a neighbouring value (a guide section that leaves late sitters out of the gain); the default over-applies it to the graded value (it also leaves their pre-test out). Three or more lines show the graded value stands. Fable cites the rule; Astra rarely misses. Measured here (build_evidence.py, 2026-10-15): final 10x2 pooled Fable 32/60, Astra 3/60; all stages Fable 55/120, Astra 4/120 (AMBIGUOUS/DEFECT units excluded). Audited GENUINE in 1 task(s). Status promising: short of proven: audited GENUINE in 1 task(s) (< 2); not dead (some model above 0.05 or n < 20).

**Recipe**

- *record:* a governing section whose rule is about a neighbouring value
- *anchors:* three or more lines (handover, record sheet, instruction) that treat the graded value as recorded
- *withheld:* no clarification that the rule covers only the neighbouring value
- *dials:*
  - each additional line that uses the graded value is one notch toward solvable
- *conservation:* grade the graded value and the neighbouring value separately
- *shields:* the shield is the trap: the audit must show the rule's grammar does not reach the graded value

**Proof obligations (authoring/validate.py)**

- scope proof: the audit quotes the rule and shows it does not reach the graded value
- three supporting lines present (grep)
- blind reader

**Hazards**

- the first audit called the melody 1.1.0 bite AMBIGUOUS; the B7 re-audit found the rule's own scope defeats the null reading (melody 1.1.0, re-audit TOO STRICT)

**What killed it**

- a stated clarification ('only the gain leaves it out'): melody 1.2.0 Fable 1/5
- line-colour 1.4.0/1.5.0 P8 colour-vision sentences: 0/10 on both

**Trace signals**

- the user objects that a rule was applied too widely
- guides with exclusion rules for one statistic

**Domains**

- school assessment
- trading plans
- council records

**Example.** A guide leaves late sitters out of the gain; the summary also drops their pre-test, though the handover and the record sheet both list it.

A first-hand record shows the item is already held, through a technical bridge the solver must make (a controller already running a known board; a vendor's job sheet for the scanned specimen).
